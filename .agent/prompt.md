Bertindaklah sebagai senior full-stack developer. Saya memiliki proyek full-stack di direktori `/fullstack-disguise` yang berisi dua sub-proyek: `disguise-backend` dan `disguise-frontend`. Keduanya sudah dilengkapi dengan dokumentasi.

Tolong lakukan langkah-langkah berikut secara berurutan:

1. **Analisis Dokumentasi & Arsitektur:**
   - Masuk ke folder `/fullstack-disguise`.
   - Baca file README atau dokumentasi lainnya yang ada di dalam folder `disguise-backend` dan `disguise-frontend`.
   - Berikan saya ringkasan singkat tentang tech stack yang digunakan (bahasa pemrograman, framework, database) dan bagaimana frontend terhubung ke backend.

2. **Persiapan Environment & Dependensi:**
   - Periksa file dependensi (seperti package.json, requirements.txt, composer.json, dll.) di kedua folder.
   - Jalankan perintah yang sesuai untuk menginstal semua dependensi pada kedua proyek tersebut.
   - Cari file `.env.example` atau file konfigurasi environment sejenisnya. Jika ada, buatkan file `.env` untuk saya dengan nilai default lokal, atau tanyakan kepada saya jika kamu membutuhkan kredensial spesifik (seperti password database).

3. **Eksekusi:**
   - Jalankan server backend terlebih dahulu.
   - Jalankan server frontend.
   - Tolong tampilkan URL atau port localhost yang tepat agar saya bisa mengakses kedua aplikasi tersebut di browser.

Jika kamu menemukan error saat proses instalasi dependensi atau saat menjalankan server, tolong analisis log error-nya, jelaskan apa yang salah, dan cobalah untuk memperbaikinya secara otomatis.
